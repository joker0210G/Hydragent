# 🐉 Hydragent Remake Docs Hub

Hydragent Remake is organized as a small set of focused specs. This page is the map. Start here, then jump into the layer or subsystem you want to change.

## Reading Order

1. [ARCHITECTURE.md](ARCHITECTURE.md) - the whole Hydragent shape.
2. [CHANNEL_GATEWAYS.md](CHANNEL_GATEWAYS.md) - edge ingestion and outbound delivery.
3. [CORE_ORCHESTRATOR.md](CORE_ORCHESTRATOR.md) - draft intake, runs, tools, and policy.
4. [MEMORY_SYSTEM.md](MEMORY_SYSTEM.md) - desk, draft paper, pages, books, shelves, Graphify.
5. [DREAMING_PHASE.md](DREAMING_PHASE.md) - compaction and memory cleanup.
6. [SECURITY_VAULT.md](SECURITY_VAULT.md) - secrets, approvals, and sandboxing.
7. [MODEL_COUNCIL.md](MODEL_COUNCIL.md) - model/provider selection.

9. [SWARM_TOPOLOGY.md](SWARM_TOPOLOGY.md) - helper agents and task splitting.
10. [ONBOARDING.md](ONBOARDING.md) - setup and first-run checks.
